# Panduan Kurasi Lapak Pasaree

1. Periksa kelengkapan: nama, foto, harga, stok, titik serah Lumbung.
2. Periksa larangan: barang terlarang, klaim kesehatan palsu, harga menipu.
3. Nilai contoh di `src/contoh-kurasi.md`.
4. Tayang bila lulus. Kembalikan ke draf beserta alasan bila belum.
5. Target layanan kurasi maksimal 1x24 jam hari kerja.
